JavaScript Array Notes

Introduction

An array is an ordered list of values in JavaScript. Arrays are zero-indexed and can store multiple values in a single variable.

Creating Arrays

1. Using Array Literals

let a = [];
let b = [10, 20, 30];

2. Using Array Constructor

let a = new Array(10, 20, 30);

Note: Prefer array literals for readability and performance.

Accessing and Modifying Elements

let a = ["HTML", "CSS", "JS"];
console.log(a[0]); // First element
console.log(a[a.length - 1]); // Last element

a[1] = "Bootstrap"; // Modifying element

Adding Elements

a.push("Node.js");      // Add at end
a.unshift("Web Dev"); // Add at start

Removing Elements

a.pop();           // Remove from end
a.shift();         // Remove from start
a.splice(1, 2);    // Remove 2 elements from index 1

Array Length

let len = a.length;
a.length = 7; // Increase length
a.length = 2; // Truncate

Iterating Arrays

Using for loop:

for (let i = 0; i < a.length; i++) {
  console.log(a[i]);
}

Using forEach:

a.forEach(function(x) {
  console.log(x);
});

Array Operations

Concatenation

let c = a.concat(b);

Convert to String

console.log(a.toString());

Check Array Type

console.log(Array.isArray(a));
console.log(a instanceof Array);

Important Note

const a1 = [5];
const a2 = new Array(5);

a1 is [5], while a2 is an array of 5 empty slots.
